# A2G Figure Case Study

This directory contains a sanitized example of the publication-figure route:

- `A2G_current_best_main_figure_editable.svg`: native vector paths and text;
- `A2G_current_best_main_figure_editable.pptx`: editable authoring source;
- `A2G_current_best_main_figure_vector.pdf`: vector publication candidate;
- `A2G_current_best_main_figure_4K.png`: raster preview;
- `A2G_WisArt_component_board_4K_reference.png`: visual vocabulary reference;
- `A2G_current_best_figure_manifest.json`: provenance and editability metadata;
- `A2G_current_best_QA_report.md`: evidence, visual, technical, and formula QA;
- `A2G_current_best_caption.txt`: bounded figure caption;
- `A2G_current_best_formula_sources.tex`: retained formula source.

The generated board is not the scientific source. It was used for palette,
component silhouettes, and visual language only. Scientific topology, labels,
connectors, formulas, and claims were reconstructed as editable objects.

The evidence boundary is intentionally explicit: fold 0, seed 42,
validation-only supporting evidence, no test or window-test access, and no
universal-SOTA, five-fold, or multi-seed claim.
